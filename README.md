# CODE ROOT

تطبيقُ المصطلحات الطبية — فكِّك الكلمة بدل أن تحفظها.

الموقع ملفٌّ واحد: `public/index.html`. لا أمر بناء ولا اعتماديّات.

## النشر

Cloudflare Pages متّصلٌ بهذا المستودع. كل دفعةٍ إلى `main` تُنشر تلقائيًّا.

- **Build command**: (فارغ)
- **Deploy command**: `npx wrangler deploy`

الإعداد في `wrangler.jsonc`: مجلّد الأصول `./public` بلا شيفرة خادم.

## الملفّات

| الملف | ما هو |
|---|---|
| `public/index.html` | التطبيق كاملًا — الشيفرة والمحتوى والصور مضمّنة |
| `public/manifest.webmanifest` | ليُضاف إلى الشاشة الرئيسية |
| `public/icon.*` | الأيقونات |
| `public/_headers` | ترويسات التخزين المؤقّت والأمان |

## أدوات التشخيص

| العنوان | ما يفعل |
|---|---|
| `?debug=1` | مقياسٌ على الشاشة: رقم البناء، الإطارات، المهامّ الطويلة |
| `?x=all` | يُطفئ كل المؤثّرات البصرية — لعزل سبب أي تقطيع |
| `?x=anim,crow,bg,path,shadow,tabs` | يُطفئ مشتبهًا واحدًا أو أكثر |
