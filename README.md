# CODE ROOT

تطبيقُ المصطلحات الطبية — فكِّك الكلمة بدل أن تحفظها.

الموقع ملفٌّ واحد: `index.html`. لا أمر بناء ولا اعتماديّات.

## النشر

Cloudflare Pages متّصلٌ بهذا المستودع. كل دفعةٍ إلى `main` تُنشر تلقائيًّا.

- **Build command**: (فارغ)
- **Build output directory**: `/`

## الملفّات

| الملف | ما هو |
|---|---|
| `index.html` | التطبيق كاملًا — الشيفرة والمحتوى والصور مضمّنة |
| `manifest.webmanifest` | ليُضاف إلى الشاشة الرئيسية |
| `icon.svg` · `icon-180/192/512.png` | الأيقونات |
| `_headers` | ترويسات التخزين المؤقّت والأمان |

## أدوات التشخيص

| العنوان | ما يفعل |
|---|---|
| `?debug=1` | مقياسٌ على الشاشة: رقم البناء، الإطارات، المهامّ الطويلة |
| `?x=all` | يُطفئ كل المؤثّرات البصرية — لعزل سبب أي تقطيع |
| `?x=anim,crow,bg,path,shadow,tabs` | يُطفئ مشتبهًا واحدًا أو أكثر |
